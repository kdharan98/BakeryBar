# Bakery Bar — Interactive Website Prototype

A responsive React + Vite prototype for the Bakery Bar bakery/e-commerce website.

## Run on a computer

1. Install Node.js (18 or newer).
2. Extract this ZIP and open the `bakery-bar-prototype` folder in VS Code.
3. In a terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

To create a production build:

```bash
npm run build
```

## What's included

- Responsive home page and navigation
- Product categories, search and sorting
- Product details, size selection and quantity controls
- Shopping bag saved in browser localStorage
- Demo checkout flow (no payment gateway)
- Account, story and contact pages
- Sample product photography from Unsplash

## Important prototype notes

- Product photos and customer reviews are placeholders. Replace them with the bakery's approved photos and genuine reviews before launch.
- Contact details, address, opening hours and prices are sample content. Confirm them with the bakery.
- Checkout is a front-end demonstration only. It does not process payments, send orders or store customer details on a server.
- The Bakery Bar logo is represented by a simple text/icon lockup. Replace it with the supplied official logo asset before launch.
- Search requires an internet connection for the remote sample images and Google Fonts.
